# Project Scripts

This directory contains utility scripts for managing the GhostTalk project.

## Available Scripts

### `init_env.sh`

Generates a new `.env` file from the `.env.example` template. This is useful for first-time setup.

**Usage:**
```bash
./scripts/init_env.sh
```

### `seed_db.sh`

A placeholder script for running database seeders to populate the database with initial data for development or testing. (Currently not implemented).

**Usage:**
```bash
./scripts/seed_db.sh
```
