# Contributing to ChatApp (by aarchangel)

First off, thank you for considering contributing to ChatApp! It's people like you that make ChatApp such a great community.

## Where do I go from here?

If you've noticed a bug or have a feature request, [make one!](<YOUR_PROJECT_ISSUES_URL_HERE>). It's generally best if you get confirmation of your bug or approval for your feature request this way before starting to code.

If you have a general question, you can also ask in our [discussion forum/channel](<YOUR_DISCUSSION_URL_HERE>).

## Fork & create a branch

If you decide to fix a bug or implement a feature, great! Fork the repository and create a new branch with a descriptive name.

A good branch name would be (where issue #38 is the ticket you're working on):

```bash
feature/38-add-rocket-ship-button
```

## Code Style and Conventions

Please adhere to the standard Kotlin coding conventions. Ensure your code is well-formatted and includes KDoc comments where appropriate.

## Commit Messages

Please write clear and concise commit messages. A good commit message should describe what changed and why.

Example:
```
feat: Add rocket ship button to main toolbar

This commit introduces a new button to the main application toolbar
that allows users to launch a rocket ship. Closes #38.
```

## Submitting a Pull Request

When you're ready to submit your changes, create a Pull Request from your fork to the main repository.

*   Ensure your PR description clearly describes the problem and solution. Include the relevant issue number if applicable.
*   Make sure all tests pass.
*   Request a review from one or more maintainers.

## Code of Conduct

By contributing to ChatApp, you agree to abide by the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md).

## Getting Help

If you need help, don't hesitate to ask on our [discussion forum/channel](<YOUR_DISCUSSION_URL_HERE>) or in the relevant GitHub issue.

Thank you for contributing!
